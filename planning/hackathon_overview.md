# Amazon Developer Hackathon: Build, Ship, Shape 🚀

## 📅 The Clock is Ticking
- **Deadline:** October 24, 2026 (12:00 AM GMT+5)
- **Time Left:** ~15 days.

## 🏆 The Goal
Build a working app or integration for one of Amazon's key platforms and submit a **3-minute demo video** + **GitHub code**.

| Track | What is it? | Key Tech | Best For |
| :--- | :--- | :--- | :--- |
| **Alexa+** | The new AI-powered Alexa | MCP (Model Context Protocol), Agent Skills | AI assistants, smart automation |
| **Bee** | Wearable AI device | Bee CLI, Real-time data processing | Health, Productivity, Education |

## 💡 How to WIN (Judging Criteria)
1. **Tech Implementation:** Does it actually work? Does it use the SDKs properly?
2. **Design:** Is it easy and pretty to use?
3. **Potential Impact:** Does it solve a real problem for real people? (Amazon's favorite)
4. **Quality of Idea:** Is it creative and "new"?

## 🚀 Strategy for Winning
- **The "10% Bonus":** Submit a "Friction Log" (a diary of what was hard or buggy while you were building). This is an easy way to boost your score.
- **Layering Challenges:** You can enter the "AWS Builder" challenge (use AWS Bedrock/AI) or the "Open Source" challenge with the same project to win extra prizes.
- **Focus on AI:** Since Alexa+ and Bee are central, using AI/LLMs is a huge advantage.
