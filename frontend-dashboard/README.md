## What this is

This is the **Next.js 14 frontend** for EchoForge. It provides:

- 🎙️ **Hands-free ambient voice loop** using the browser Web Speech API with real-time wake word barge-in detection ("Echo", "Alexa", "Stop", "Cancel")
- 📊 **Aerospace Tolerance Deviation Gauge** — animated needle that shows live micron-level deviations
- 🤖 **AWS Bedrock AgentCore integration** — autonomous tool orchestration via Amazon Nova Pro
- 🔧 **CNC Repair Procedure retrieval** — autonomous G-code and repair directives generated by AI
- 📈 **Statistical Process Control (SPC) drift sparkline** — tracks machine tool wear over batch runs

The frontend connects to our live **EchoForge MCP Server** at `https://echoforge-mcp-fresh.onrender.com` which parses legacy `.DMO` aerospace inspection files in real-time.

## Quick Start

### Prerequisites
- Node.js `18.x` or `20.x` LTS
- AWS credentials with `bedrock-agentcore:InvokeHarness` permission

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment variables
```bash
cp .env.example .env.local
```

Open `.env.local` and fill in your AWS credentials:
```env
APP_AWS_REGION=us-east-1
APP_AWS_ACCESS_KEY_ID=your_key_here
APP_AWS_SECRET_ACCESS_KEY=your_secret_here
```

### 3. Verify the build
```bash
npm run build
```

### 4. Run locally
```bash
npm run dev
# Open http://localhost:3000
```

> **Note:** Use **Google Chrome** or **Microsoft Edge** for full Web Speech API and SpeechSynthesis support.

## How the Voice Loop Works

1. User clicks the microphone button (or enables **Hands-Free** mode)
2. The browser Web Speech API captures the voice query
3. The query is sent to `/api/agent` (AWS Bedrock AgentCore with Amazon Nova Pro)
4. Nova Pro autonomously decides to call the MCP edge server tool (`query_dmo_deviation` / `get_repair_procedure`)
5. The result is returned and spoken aloud via Speech Synthesis
6. The ambient listener resumes for the next query
